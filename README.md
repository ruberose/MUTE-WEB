# MUTE-WEB

MUTE-WEB 프로젝트에 오신 것을 환영합니다!

## 소개
이 저장소는 **MUTE-WEB** 프로젝트의 웹 애플리케이션 소스 코드가 관리되는 곳입니다.

## 시작하기

### 사전 준비 사항
이 프로젝트를 실행하려면 [Node.js](https://nodejs.org/)가 설치되어 있어야 합니다.

### 설치 및 실행
```bash
# 의존성 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```
